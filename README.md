نظام محاسبة كامل يعمل من المتصفح مع القيد المزدوج.

## ✨ المميزات المُنجزة في الأسبوع الأول

- ✅ تسجيل دخول متعدد المستخدمين
- ✅ إدارة الشركات (متعددة)
- ✅ دليل حسابات كامل (يُنشأ تلقائياً عند إضافة شركة)
- ✅ الصناديق والبنوك
- ✅ القيود اليومية (قيد مزدوج مع تحقق من التوازن)
- ✅ دفتر اليومية
- ✅ دفتر الأستاذ
- ✅ ميزان المراجعة
- ✅ لوحة تحكم مع إحصائيات
- ✅ PWA (قابل للتثبيت)

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعاً جديداً باسم: `erp-accounting-system`
2. ارفع الملفات الأربعة
3. Settings → Pages → Branch: main → / (root) → Save
4. الرابط: `https://USERNAME.github.io/erp-accounting-system/`

## 🔑 بيانات الدخول

- المستخدم: `admin`
- كلمة المرور: `admin123`

## 🌱 البيانات التجريبية
