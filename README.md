# 🏢 نظام ERP المحاسبي المتكامل

نظام محاسبة احترافي كامل يعمل من المتصفح مباشرة.

## ✨ المميزات
- 🏢 تعدد الشركات
- 🏬 تعدد المستودعات (رئيسي/فرعي/إنتاج/تالف)
- 💱 تعدد العملات + أسعار صرف
- 📋 جرد مستمر وجرد دوري
- 🏭 عمليات التصنيع (BOM)
- 👥 تعدد المستخدمين (4 أدوار)
- 👤 إدارة العملاء
- 🧾 الفواتير (مبيعات/مشتريات)
- 💵 المدفوعات الجزئية
- 📄 كشوف الحسابات
- 📱 إرسال الفواتير وكشوف الحسابات بالواتساب
- 📊 رسوم بيانية تفاعلية
- 📲 PWA (قابل للتثبيت على الجوال)
- 💾 تخزين محلي IndexedDB

## 🚀 النشر على GitHub Pages

1. أنشئ مستودعاً جديداً (Public) باسم: `erp-accounting-system`
2. ارفع الملفات: `index.html`, `manifest.json`, `sw.js`
3. Settings → Pages → Branch: main → / (root) → Save
4. الرابط: `https://USERNAME.github.io/erp-accounting-system/`

## 🔑 بيانات الدخول
- المستخدم: `admin`
- كلمة المرور: `admin123`

## 🌱 بيانات تجريبية
في شاشة الدخول اضغط على "🌱 تحميل بيانات تجريبية" لإنشاء:
- شركة + مستودعين + 4 منتجات + عميلين
- فاتورة + حركات مخزون + عمليات مالية
